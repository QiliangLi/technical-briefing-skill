# Offline Demo Output

This folder is a static copy of one end-to-end fixture run. It exists so the Skill can be inspected without network access or model credentials.

- `email.html`: final responsive HTML email.
- `cards.html`: Guizang-compatible/fallback social-card sheet.
- `issue.json`: approved issue data contract.
- `validation.json`: validation result.
- `relevance-task.input.json` / `relevance-task.output.json`: one example of the Agent task interface.

The fixture uses `example.com` and deliberately short copy. It demonstrates orchestration only and must not be sent as a real briefing.
