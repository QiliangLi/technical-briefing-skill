# Documentation history

This directory preserves dated material that is useful for archaeology but no longer defines current behavior.

- `plans/` contains earlier implementation and optimization plans.
- `releases/` contains the v0.1.0 implementation snapshot and its test report.
- `research-notes/` contains code reviews, design explorations, conversation exports, and personal visual notes that formerly lived in a separate top-level directory.
- `designs/` is reserved for implemented or superseded design records whose durable rules have already been moved into current documentation.

Use `../architecture.md`, `../operations/`, `../contracts/`, the repository `README.md`, and `SKILL.md` for current guidance. When a historical idea becomes active, restate the accepted contract in the appropriate current document instead of linking runtime behavior to a dated report.
