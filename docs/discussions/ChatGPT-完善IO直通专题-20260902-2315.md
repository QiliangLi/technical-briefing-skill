其中 **②最好设成重点权重最高**。因为它代表的并不是传统意义上的“高性能 I/O”，而是 **I/O ownership 从 CPU 向 GPU/Accelerator 转移**。

例如：

**传统：**

`GPU → CPU → OS/File System → NVMe Driver → SSD`

**GDS：**

`CPU 发起/管理 I/O → SSD DMA → GPU Memory`

数据绕开 CPU 内存，但 CPU 仍然参与控制。

**SCADA / BaM / GIDS 类：**

`GPU Thread → Storage Request → NVMe/Storage → GPU Memory`

GPU 开始同时成为 **计算者 + I/O requester**。NVIDIA 当前对 SCADA 的定义就是 GPU 直接 initiate/control storage operations，重点针对 `<4 KB` 的细粒度 I/O 和数千乃至大量 GPU 并行线程。([NVIDIA](https://www.nvidia.com/en-us/on-demand/session/gtc25-s73012/?utm_source=chatgpt.com))
