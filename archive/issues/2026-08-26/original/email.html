内存涨价重排AI产业：存量算力的成本优势不再闭合

论文/来源：Memory Scarcity, Open Models, and the Restructuring of the AI Industry, 2026-2030 -- A quantitative scenario analysis of inference economics, training-cost divergence, and infrastructure solvency

这是一份定量情景报告，讨论DRAM/HBM涨价、开放权重模型、推理效率提升和算力转售四股力量如何重构2026到2030年的AI产业。计价单位选得很讲究，按每PB内存带宽的美元算，而不是按峰值算力。

为什么会这样

反直觉的结论在折旧传送带。摊销完毕的旧舰队持续交付给存量方，速度快过硬件价格正常化。新进入者的成本差距2026年是3.2倍，2027年收窄到1.9倍，之后重新扩大到3倍以上，优势在存量方之间轮换，永远传不到新进入者手里。

关键结果

训练成本分层拉到三四个数量级，前沿训练2030年要180亿到380亿美元，开放基座复刻降到约500万美元。基础设施偿付需要token需求连续四年翻倍增长，交付窗口靠后的产能暴露最大。

token相位的内存瓶颈，用免重载KV布局加全融合解开

论文/来源：FastTPS: An Optimized Method for LLM Token Phase for AI accelerators

过程奖励模型不用重读轨迹：直接读生成时的KV缓存

论文/来源：KV-PRM: Efficient Process Reward Modeling via KV-Cache Transfer for Multi-Agent Test-Time Scaling

过程奖励模型指导测试时扩展很有效，但每次打分都要把整条轨迹文本从头编码一遍，成本随长度平方涨。KV-PRM的思路简单直接。生成阶段已经算出了KV缓存，打分时何必再读一遍文本。

怎么做的

对既有KV缓存前向一个verify token就输出奖励，打分成本从平方降到线性。训练时冻结基座只更新LoRA，梯度只流过verify token这一步。作者还形式化证明了KV缓存的信息容量严格大于文本。

关键结果

MATH、GSM8K和AIME上匹配或严格优于文本PRM，打分FLOPs最高省5000倍，时延省37倍，每序列内存省34倍。

论文/来源：Task-CoEvolve: Efficient Harness Optimization via Adaptive Validation Task Selection

自动改Harness的流程里，评测通常是大头。每轮把每个候选在整套验证任务上跑一遍，Terminal-Bench这类任务一次占沙盒几十分钟，评测费用压过优化本身。东京大学这篇让验证任务集跟着Harness一起演化，预算优先给候选之间结果分歧大的任务，再按采样概率把分数折算回全集，不同轮次之间仍然可比。

验证证据和新鲜度直接署名进代码，检索摘要不用再猜

论文/来源：Executable Code Knowledge: Code as a Native, Validation-Carrying Knowledge Representation for AI Coding Agents

编码Agent拿到检索片段，还是不知道哪个是业务规则、哪条测试管这段代码、摘要是不是过期了。ECK换了个方向，用装饰器把这些信息直接署名进代码单元。每个ECKU带身份、语义、契约、证据和查询接口，证据能执行，新鲜度能检查。

关键结果

消融把证据的价值量了出来。隐藏声明证据后，精确选择器从9/11掉到1/11；补丁影响对12条链接的精度和召回都是1.000；50个过期扰动里ECK全部检出，规则快照一个都没发现。

可以怎么验证

对仓库索引方向，这套实验支持一个分层做法。规则文件继续当投递层，证据、影响和新鲜度放进源绑定对象里治理，别外置给摘要。17个单元只盖住11个补丁，也说明它替代不了检索。

KV驱逐丢的是信息不是能力，找个小模型补回来

论文/来源：KV-Rescue: Recovering Reasoning Language Model KV Eviction Loss via Stepwise Interleaving
为什么会这样

被驱逐的大模型和全上下文的小模型会犯互补的错误。前者看不见部分历史，后者能力不足，两者oracle择优能恢复全KV大模型近八成的驱逐损失。KV-Rescue照这个思路把两个模型的推理步交错进同一条轨迹，按步择优提交，再用熵和可压缩性在线掐掉重复或不连贯的分支。

需要注意

这是本地KV机制，不碰跨域传输；辅助模型的KV随上下文增长，评测也只覆盖数学推理域。

拆开MLA的瓶颈：内容留下了，位置丢掉了

论文/来源：Through the Bottleneck: How Multi-head Latent Attention Separates Content from Position in Language Models
怎么做的

研究者训练了一个114M的MLA模型，用SVD、192个头的功能分类、线性探针和扰动归因四组实验拆开低秩瓶颈。结论是cKV学到纯内容表示，实体身份保留98%，位置信息探测接近随机，验证了MLA把内容走瓶颈、位置走RoPE的设计确实被模型学到。

关键结果
