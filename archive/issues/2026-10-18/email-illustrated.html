远程KV缓存命中为什么比重算慢：一个成本模型与秩分片修复

论文/来源：When the KV Cache Is Slower Than the GPU: Scaling Remote KV Tiers for Context-Parallel Prefill

生产部署中的远程KV层把16k提示的p99 TTFT从3.96秒推高到17.3秒——缓存命中反而比重算慢。论文给出一个成本模型，说明每提示可用的带宽与固定开销共同决定命中能否胜过重算，并据此修复了存储层。

怎么做的

模型给出带宽阈值B*≈2.53GB/s与固定开销T0≈0.33秒：带宽不达标时，17k以内的提示命中必然慢于重算。修复是PCP秩分片，每秩一个Valkey，加载改为异步。

关键结果

重放命中密集流量时，p99从83.32秒降到0.67秒，降幅124倍，98.5%的token仍由L2提供；8路200k提示的吞吐较秩0存储升14%-15%。留意两点：每条件只运行了一次，10%以内的差异未确立；中位数仍比重算慢0.09秒，且评估仅覆盖预填充、单引擎。

论文/来源：An Optical KV Cache Network for Disaggregated LLM Serving

调度怎么判断

StateHarness：为长程编码Agent维护演化的外部项目状态

论文/来源：StateHarness: Maintaining Evolving Project State for Long-Horizon Coding Agents

关系怎么查询
