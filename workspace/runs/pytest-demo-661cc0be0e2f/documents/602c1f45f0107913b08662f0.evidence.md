# Breaking AI Memory Limits with CXL Memory Pooling

Source: https://semiconductor.samsung.com/news-events/tech-blog/breaking-ai-memory-limits-with-cxl-memory-pooling/

## Evidence locator: Available summary

## Available summary

Samsung's evaluation of CXL memory pooling (CMM-D modules through a CXL switch, 1TB pool) for offloading LLM KV cache, reporting near-DRAM performance (approximately 92% of DRAM at 8 GPUs) and stable throughput under growing KV cache demands where DRAM degraded.
