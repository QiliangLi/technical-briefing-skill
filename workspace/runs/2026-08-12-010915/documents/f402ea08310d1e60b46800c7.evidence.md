## Peer-to-Peer (P2P) KV Cache Transfer

This release introduces full P2P support for multiprocess (MP) mode , enabling direct KV cache lookup and transfer between LMCache instances:

- P2P adapter introduced ([ #3740 ]( #3740 )), with finalized wiring ([ #3762 ]( #3762 )) and an end-to-end example ([ #3781 ]( #3781 ))

- Transfer channel abstraction for MP mode ([ #3712 ]( #3712 ))

- New RPC interface for P2P lookup and lock ([ #3728 ]( #3728 ))

- P2P info into MP coordinator ([ #3706 ]( #3706 ))

- Runtime registration / deregistration of L2 adapters ([ #3743 ]( #3743 ))

- P2P documentation added ([ #3780 ]( #3780 ))

- Bugfixes: release P2P transfer-channel client when adapter is removed ([ #3778 ]( #3778 ))
