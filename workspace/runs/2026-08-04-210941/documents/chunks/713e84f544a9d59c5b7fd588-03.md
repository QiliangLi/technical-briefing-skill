### 4.1. Network planning and design for the data collection and pre-processing stage

The core of the global training data aggregation and pre-processing network solution is to provide large-scale, elastic public IP addresses and bandwidth resources—supporting efficient collection of massive raw training data from the global Internet. Leveraging Alibaba Cloud’s global infrastructure, the solution delivers many independent public IP addresses and high-bandwidth egresses on demand. This effectively resolves IP exhaustion, concurrency limits, and bandwidth bottlenecks during collection—significantly improving data retrieval concurrency and success rates. After collection, the solution seamlessly integrates with cross-region high-speed transmission capabilities. It uses Alibaba Cloud’s global network to achieve low-latency, high-throughput data aggregation across regions—ensuring data collected from dispersed locations is centralized quickly and stably at designated computing nodes for pre-processing. The solution ensures resource supply at the public network collection end—and establishes data flow channels across multiple regions worldwide—achieving efficient end-to-end synergy for “collection-transmission-pre-processing.” Its advantages—resource elasticity, global deployment, and cross-domain interconnection—build a high-performance data pipeline for LLM training.

### 4.2. Network planning and design for the model training stage

The model training network is tightly integrated with the data collection and pre-processing network. The training network consumes the massive datasets that have been collected and pre-processed—so they jointly form a global network. This network spans regional boundaries—connecting cloud data centers, edge nodes, and on-premises IDCs—and achieves low-latency, high-throughput data flow through high-speed interconnections such as Alibaba Cloud CEN, TR, and GA. After data is collected from sources—such as IoT devices, behavioral logs, and public datasets—it is written to a high-performance storage system—such as CPFS, OSS, or NAS—through a pre-processing pipeline—including cleaning, annotation, format conversion, and feature engineering. The training cluster then pulls the data as needed. To ensure end-to-end efficiency, the entire link must be designed with coordinated bandwidth, security policies, access control, and disaster recovery capabilities. For example, pre-processing tasks can be deployed in a region close to the data source to reduce transmission overhead—while training tasks are scheduled to a LINGJUN Cluster with RDMA acceleration capabilities. At the same time, unified VPC planning and routing policies ensure data flows seamlessly, securely, and efficiently through the collection, pre-processing, and training stages. This integrated network and data architecture has become the core infrastructure supporting AI engineering in the era of large models. This chapter introduces the design of the training network.
