Route table design

- System route table (default): 1) After creating a VPC, a system route table is created by default. This table has routes to all vSwitches in the VPC. 2) When there is a need for public network egress and an IPv4 gateway is configured, add a route with the prefix 0.0.0.0/0 and the next hop pointing to the IPv4 gateway. 3) This table is associated with the public subnet (public SLB vSwitch, public NAT vSwitch). 4) When a pod in the node subnet with a bound EIP wants to directly access the public network, it also needs to be associated with this table.
