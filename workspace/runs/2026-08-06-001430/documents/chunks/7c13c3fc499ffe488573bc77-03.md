D.1 ALFWorld: Abstracting and Transferring Skills
In ALFWorld, verbatim replay of the retrieved memory would introduce hallucinated objects (“credit

shown in Figure 12, MemHarness instead extracts the underlying procedural skill (placing a held

(“cup” and “sidetable”).
D.2 WebShop: Grounding Heuristics into Actionable Targets
In WebShop, the retrieved memory is often an abstract heuristic (e.g., advising the agent to cross-
check specific constraints before clicking). A naive replay would simply append this abstract rule to
the prompt, offering no concrete operational help. As shown in Figure 13, MemHarness executes this
heuristic during the reconstruction phase: it scans the current noisy observation, aligns it with the
user’s constraints, and directly outputs the exact target ID to act upon.
