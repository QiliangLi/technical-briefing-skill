ROCm 7.2 wheel for LMCache v0.5.3rc4, built for AMD Instinct gfx942 (MI300X/MI325X) and gfx950 (MI350X/MI355X). ABI-matched to the upstream vllm/vllm-openai-rocm image (torch 2.11, cp312).

Install into an upstream vLLM ROCm container:

VERSION=v0.5.3rc4
pip install lmcache==${VERSION#v} --no-deps \
  --find-links https://github.com/LMCache/LMCache/releases/expanded_assets/${VERSION}-rocm
