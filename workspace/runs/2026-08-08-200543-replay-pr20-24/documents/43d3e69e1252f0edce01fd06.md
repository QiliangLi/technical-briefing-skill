# Oracle Agent Memory as an Enterprise Memory Substrate for Long-Horizon AI Agents

Source: https://arxiv.org/abs/2607.13157

## Available summary

Proposes a database-native memory substrate built on Oracle Database, with a layered architecture separating an active memory core from a passive store interface; reports 93.8% accuracy on LongMemEval using ~10.7x fewer tokens than flat-history baselines.
