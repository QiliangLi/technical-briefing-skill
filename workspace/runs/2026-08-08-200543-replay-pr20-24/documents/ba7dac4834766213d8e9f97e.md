# Governed Shared Memory for Multi-Agent LLM Systems

Source: https://arxiv.org/abs/2606.24535

## Available summary

Formalizes the 'fleet-memory problem' for cooperating LLM agents and proposes systems primitives (scoped retrieval, temporal supersession, provenance tracking, policy-governed propagation) implemented in the MemClaw reference system, evaluated via the ArgusFleet harness.
