# Agent语义加速：专题判断卡

Agent语义加速指减少Agent反复Read、Grep、Glob、代码探索、上下文定位、规划等待和工具调用，从而缩短端到端任务完成时间的技术。它不等同于语义缓存。

当前重点判断：

1. CodeGraph、RepoGraph或仓库索引是否减少真实任务中的重复读取和搜索。
2. 优化对象是检索、上下文构建、工具执行链还是规划关键路径。
3. 是否报告Read/Grep/tool call次数、Token消耗、任务成功率和端到端时延。
4. 索引构建、仓库更新、误命中、异步校验和错误恢复成本是否被说明。
5. 是否能直接启发代码Agent中的“搜索符号—读取文件—定位调用链—修改—验证”路径优化。
