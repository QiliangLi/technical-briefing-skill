# AI芯片与加速器：专题判断卡

关注用于AI训练和推理的GPU、NPU、TPU、ASIC及其他专用加速器。重点不是新品罗列，而是判断芯片架构、Chiplet与先进封装、片上和封装级互联、HBM/HBF接口及软硬件协同是否带来可验证的系统收益。

当前重点判断：

1. 新设计解决的是计算、访存、通信、功耗还是扩展性瓶颈，机制是否明确。
2. 峰值TOPS、TFLOPS或带宽是否转化为真实训练或推理吞吐、时延和性能功耗比。
3. 对比基线、精度、批量、模型规模、制程、功耗和封装条件是否完整。
4. 结果属于仿真、预硅验证、实验芯片、工程样片还是量产部署。
5. 与HBM、HBF、CXL、AI Fabric和系统软件的边界是否清楚，避免把整机收益全部归因于单颗芯片。

优先保留：有架构图、芯片或系统实测、明确基线、功耗数据、封装或内存带宽数据，以及真实部署规模的论文、官方技术报告和产品文档。

降低优先级：只有峰值参数、市场宣传、供应链传闻、股价和市场份额，没有机制与实测条件的内容。
