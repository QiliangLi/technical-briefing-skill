# 存储介质与器件：项目判断卡

## 当前关注的问题

- 介质侧的容量密度、带宽、时延、耐久、功耗和成本变化，是否足以改变现有存储层级或设备形态？
- HBF、QLC/PLC、新型非易失存储或HAMR等方向，哪些已经从器件指标进入系统可用阶段？
- 介质创新的收益在控制器、接口、软件栈和真实工作负载下还能保留多少？

## 值得进入本期判断的证据

优先保留能够回答“介质参数如何转化成系统价值”的证据：量产/原型节点、容量与密度、顺序/随机带宽、访问时延、P/E耐久、写放大、功耗、成本/bit，以及与现有NAND/HDD/DRAM层级的明确对照。单纯材料机理、没有器件或系统量化结果的工作通常只作为观察信号。

## 判断边界

- HBM及其封装/带宽问题优先归入AI芯片与加速器专题，除非工作核心是非易失介质替代。
- CXL内存池化、共享语义和远程访问优先归入内存语义专题。
- DPU、NVMe-oF、协议卸载等数据路径优化不因使用SSD而归入介质专题。
- 厂商路线图必须区分宣布、送样、量产和规模部署，不能把规划指标写成已实现能力。
