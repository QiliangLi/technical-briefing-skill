# AI Infra横向动态判断卡

## 当前问题

- 该进展是否直接影响AI训练、推理或Agent的端到端效率、成本、可靠性或可扩展性？
- 它是否包含可复核的系统机制、性能数据、部署规模或工程约束？
- 它能否归入已配置的深度专题；若不能，是否值得作为跨专题基础设施变化单独跟踪？

## 有价值证据

- 端到端时延、吞吐、GPU利用率和任务完成时间；
- 真实集群或生产部署规模；
- 资源调度、故障恢复和可观测性数据；
- 加速器、内存层次、存储或互联的明确架构变化；
- 与现有方案的可复核对比及适用边界。

## 排除内容

- 模型融资、股价、季度财报和高管观点；
- 政策争议、版权诉讼和泛产业评论；
- 游戏、影视、消费应用和缺少技术机制的产品宣传。
