# KVCache管理与复用：专题判断卡

关注单机与单集群内KVCache的存储管理：RadixTree与前缀缓存复用、分页与块管理、驱逐策略以及GPU/CPU/SSD之间的分层放置。跨节点与跨域传输归TPN和跨域传输专题判断。

当前重点判断：

1. RadixTree或前缀缓存在真实多轮、多请求负载下的命中率，以及命中率兑换成TTFT、TPOT和吞吐的幅度。
2. 分页与块管理是否真正降低显存碎片并提高GPU显存利用率，元数据与分配开销是否抵消收益。
3. KVCache在GPU、CPU与SSD之间分层放置时，容量、带宽与命中率三者的收益边界在哪里。
4. 驱逐与复用策略是否利用了请求间前缀共享或任务语义，而不只是通用LRU。
5. 本地复用与跨节点KVCache传输（TPN、跨域传输专题）如何组合，先复用还是先迁移。
